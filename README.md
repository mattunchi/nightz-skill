# Nightz Booking Skill for OpenClaw

Book nights at Nightz properties on Base through your AI agent.

## What is Nightz?

1 token = 1 night at a specific property. Buy at the launch price → hold your dates → burn → stay confirmed. On Base (Coinbase L2).

## What this skill does

Install this skill and your OpenClaw agent can:
- Browse available properties
- Check real-time pricing & availability
- Buy night tokens from launchpad
- Hold dates, burn tokens and confirm the booking
- Query your reservations (wallet-signed)
- Track affiliate commissions across sales

## Install

```bash
clawhub install nightz-booking
```

Or copy the `SKILL.md` and `references/` folder into your OpenClaw `skills/nightz-booking/` directory.
