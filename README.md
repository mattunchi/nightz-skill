# Nightz Booking Skill for OpenClaw

Book tokenized vacation nights on-chain through your AI agent.

## What is Nightz?

1 token = 1 night of stay. Buy tokens → burn them → book your dates. Everything on-chain on Base (Coinbase L2).

## What this skill does

Install this skill and your OpenClaw agent can:
- Browse available properties
- Check real-time pricing & availability
- Buy night tokens from launchpad
- Burn tokens to book dates on-chain
- Query your reservations
- Swap tokens on Uniswap secondary market

## Install

```bash
clawhub install nightz-booking
```

Or copy the `SKILL.md` and `references/` folder into your OpenClaw `skills/nightz-booking/` directory.
